# CookieGate v0.1.1 Hardening Plan

## Status

Chrome Web Store: submitted / in review  
Firefox AMO: submitted / awaiting review  
Public repo: https://github.com/ScrappyHub/CookieGate  
Privacy policy: https://github.com/ScrappyHub/CookieGate/blob/main/PRIVACY.md

## Rule

Do not change or resubmit v0.1.0 unless a store reviewer requests it.

All work here targets v0.1.1.

## v0.1.1 Goals

1. Replace unsafe `innerHTML` render paths with DOM node builders where practical.
2. Preserve CookieGate behavior:
   - active-site cookie inspection
   - browser observer
   - manual wipe planning
   - auth/session preservation by default
   - hash previews instead of raw cookie value export
3. Fix Browser Observer chart/donut polish.
4. Clean Chrome/Firefox packaging scripts.
5. Keep generated artifacts out of Git:
   - dist/
   - release/
   - submit/
   - proofs/
   - node_modules/

## Review Notes

AMO v0.1.0 passed validation with warnings for `innerHTML`. These warnings are not store blockers, but they are the first hardening target.

## Definition of Done

v0.1.1 is ready when:

- `node --check ui/popup.js` passes.
- Firefox AMO validation has no hard errors.
- Chrome package loads from `dist/chrome-current`.
- No generated artifacts are tracked by Git.
- The Browser Observer chart is visually improved or deliberately simplified.
- A new submission package is produced only after local visual testing passes.
