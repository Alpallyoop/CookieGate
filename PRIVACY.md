
# CookieGate Privacy Policy

## Effective date: 2026-05-26

---

CookieGate is a local-first browser privacy extension that helps users inspect browser cookies and create user-controlled cleanup plans.

# Single purpose

CookieGate provides local browser cookie visibility and user-controlled cleanup planning.

---

# Data processed locally

CookieGate may process cookie metadata in the browser, including:

Cookie names
Cookie domains
Cookie paths
Cookie flags such as Secure, HttpOnly, SameSite, and session status
Cookie classification labels
Local cleanup plan state
Local extension settings such as global mode, site mode, and domain rules

CookieGate may also display hash previews for cookie values. Raw cookie values are not exported by the extension.

Data not sold or transferred

CookieGate does not sell user data.

CookieGate does not transfer user data to third parties except as required by browser platform functionality initiated by the user.

CookieGate does not use user data for advertising, creditworthiness, lending, or unrelated purposes.

---

## Permissions

# cookies

Used to inspect cookie metadata and remove cookies only when the user requests cleanup.

# browsingData

Used only for optional browser cleanup actions selected by the user, such as clearing cache, local storage, IndexedDB, or service workers.

# storage

Used to save local extension settings such as global mode, site mode, domain rules, and local evidence/session state.

# tabs

Used to identify the active tab’s URL/domain so CookieGate can show the correct site context.

 # activeTab

Used to access the current tab context only when the user opens or interacts with CookieGate.

# host permissions

Used to inspect and manage cookies for domains the user chooses to review or clean.

# Remote code

CookieGate does not use remote code. All JavaScript, CSS, HTML, and extension logic are packaged inside the extension.

# User control

Cookie cleanup actions are initiated by the user. CookieGate preserves auth/session cookies by default unless the user intentionally includes them in a manual cleanup action.
